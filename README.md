Customer Segmentation

Tools & Technologies: Python, SQL, MySQL, Excel, Pandas, NumPy, Scikit-Learn, K-Means Clustering, Matplotlib, Seaborn, Git, GitHub

Developed a customer segmentation platform using Machine Learning, SQL, and Excel for customer intelligence and targeted marketing analysis. Applied K-Means Clustering to segment customers based on Annual Income, Spending Score, and Purchase Frequency. Performed customer behavior analysis using SQL aggregation, KPI metrics, and demographic segmentation. Built interactive Excel dashboards featuring KPI cards, Pivot Tables, and visual analytics for business reporting. Conducted correlation analysis and customer profiling using Python and Pandas. Visualized customer clusters through scatter plots and heatmaps using Matplotlib and Seaborn.

Model Performance:

K-Means Clustering with 3 customer segments (High Value, Medium Value, Low Value) Cluster evaluation performed using Inertia and Elbow Method Achieved clear customer group separation for targeted business strategies

Business Insights:

Identified high-value customer segments with significantly higher spending scores. Recognized medium-value customers suitable for retention campaigns. Discovered low-engagement customers requiring targeted promotions.
